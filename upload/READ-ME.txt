Папка для оригиналов фотографий перед оптимизацией.

Как пользоваться:
1. Скопируйте сюда фото (.jpg / .png / .heic / .tiff — любые).
2. Запустите в терминале:
       npm run images
3. Готовые .webp окажутся в public/works/.
   Оригиналы переедут в upload/_done/ (можно затем удалить).

Полезные флаги (через "--"):
  npm run images -- --max 1600        # уменьшить длинную сторону до 1600px
  npm run images -- --quality 85      # поднять качество (по умолчанию 82)
  npm run images -- --jpg             # дополнительно сохранить .jpg
  npm run images -- --out public/uploads/portfolio   # другая папка назначения
  npm run images -- --keep            # не двигать оригиналы в _done/
  npm run images:dry                  # сухой прогон, ничего не пишет

Имена файлов автоматически становятся kebab-case-латиницей.
Например: "Фасад на Ленинской.jpg" -> "fasad-na-leninskoy.webp".
Если хотите конкретный slug — заранее переименуйте файл в латиницу.
